# Research logs

These category-specific logs preserve sources and technical observations used to
develop the complaint log. They are research history, not normative
specification, security assurance, or evidence that a complaint is resolved.

Each dated entry records an area, primary sources where available, material facts,
their RFC implication, and whether the evidence introduced a distinct failure
mode or reinforced an existing one. A coverage label means only that an entry was
recorded; it does not establish completeness.

Current design authority is defined in
[Document authority](../DOCUMENT_AUTHORITY.md). Complaint remediation status is in
[the complaint log](../COMPLAINTS.md).
